# Customer Guide — MMK Event Ticketing & QR Pass Generator

## 1. Create an event

Enter the event name, date, time, venue, default ticket price and capacity.

## 2. Issue a ticket

Enter the attendee name and WhatsApp-capable phone number. The system creates a unique ticket code and QR pass.

## 3. Send it on WhatsApp

Use the WhatsApp button on the ticket card. WhatsApp opens with a prepared message containing the ticket download/check-in link.

## 4. At the entrance

The attendee shows the QR code. Scan it with a phone camera or open the QR link. The check-in screen shows whether the pass is valid, already used, cancelled, or invalid.

## 5. Duplicate scans

Once a valid ticket is checked in, a second attempt is reported as already checked in.

## 6. Event close-out

Use the event statistics and PDF ZIP export for a simple record of attendance and issued passes.
