# MMK Event Ticketing & QR Pass Generator — Sales Sheet

## What the client gets

A reusable web system for selling and managing event tickets digitally.

### Main features

- Create multiple events
- Set ticket price and capacity
- Issue individual tickets
- Bulk issue tickets from CSV
- Unique QR code on every pass
- Branded PDF ticket layout ready for customization
- WhatsApp-ready delivery link
- Door check-in and duplicate-scan detection
- Event attendance and revenue records
- Export ticket PDFs and attendance ledger
- Mobile-friendly interface

## Who can buy it

Clubs, lounges, DJs/promoters, churches, schools, conferences, community events, private parties and local venues.

## MMK delivery model

**Starter installation:** software setup + client event branding + basic training.

**Managed version:** hosted system + backups + support + branding.

**Custom version:** WhatsApp Business API automation, payment integration, domain/hosting, analytics, staff roles and client-specific features.

## Positioning

Do not sell this as "just a QR generator". Sell the complete event workflow:

`Ticket creation → digital pass → WhatsApp sharing → door validation → attendance record`
