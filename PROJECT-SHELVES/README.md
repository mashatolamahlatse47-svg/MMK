# MMK Project Shelves

MMK uses four shelves to organize project state.

## ACTIVE
Projects currently being built, tested, fixed, or improved.

## INCOMPLETE
Projects that have started work but are not finished and are not currently the main focus.

## PARKED
Valid projects intentionally paused for later.

## COMPLETED
Projects that have passed the MMK release gate, are documented, packaged, tested, and preserved.

## Rules

- Every project has one shelf.
- The shelf records project status; it does not automatically move project files.
- Never mark a project COMPLETED only because code exists.
- ACTIVE projects need a clear next action.
- INCOMPLETE projects need a clear missing-work note.
- PARKED projects need a reason for pausing.
- COMPLETED projects need evidence of testing, documentation, packaging, versioning, and preservation.
- Actual project files are moved only after inspection and backup.
