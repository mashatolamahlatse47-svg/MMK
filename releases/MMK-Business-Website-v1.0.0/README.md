# MMK Business Website Template

Reusable mobile-first business website template developed by MMK.

## Purpose

This template provides a reusable foundation for small businesses,
entrepreneurs, creators and service providers who need a professional
website.

## Design Foundation

The template follows the MMK visual design system:

- Dark and gold visual foundation
- Mobile-first responsive layout
- Clear typography
- Reusable sections
- Reusable cards
- Consistent buttons
- Simple customer journey
- Easy content customization

## Customer Journey

Visitor
→ Understand the business
→ View services
→ View products/projects
→ Contact the business

## Important

This is a reusable customer template.

MMK private information, contact details and internal systems must not
be included in a customer website unless explicitly configured for that
customer.
