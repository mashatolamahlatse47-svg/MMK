# MMK Stock & Profit Calculator

**Version:** 1.0.0  
**Publisher:** MMK  
**Currency:** South African Rand (R)  
**Product type:** Standalone offline browser application

## Overview

MMK Stock & Profit Calculator is a lightweight browser-based business tool for recording products, managing stock, tracking sales, and calculating revenue and profit.

The application is designed to operate locally in a web browser.

## Features

- Product stock management
- Cost price tracking
- Selling price tracking
- Stock quantity tracking
- Sell one unit
- Restock one unit
- Product deletion
- Profit calculation
- Sales recording
- Sales history
- Revenue totals
- Profit totals
- Offline browser storage
- Backup export
- Backup restore

## How to Run

1. Keep all files in the same folder.
2. Open the application through a local web server.
3. Open the application address in a browser.
4. Add or review products.
5. Use the Stock Management section to manage stock.
6. Use Sell 1 when a unit is sold.
7. Review Sales History for recorded transactions.
8. Use Export Backup regularly to protect business data.

## Data

Business data is stored locally in the browser.

The application provides an Export Backup function that saves business data as a JSON backup file.

The Restore Backup function can restore a previously exported MMK backup.

## Important

Because data is stored locally in the browser, regular backups are recommended.

Do not delete browser site data or application storage before creating a backup.

## Product Scope

This version is intended as a standalone offline business tool.

It does not require an online customer account or cloud database.
