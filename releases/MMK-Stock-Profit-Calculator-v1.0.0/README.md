# MMK Stock Profit Calculator v1.0.0

MMK Stock Profit Calculator is a simple browser-based tool for small businesses to record products, stock, sales, revenue and profit.

## Included
- Product and stock records
- Selling price and cost price
- Profit calculation
- Sell and restock controls
- Sales history
- Data backup and restore

## Run
Open index.html in a modern web browser, or serve the folder with a local web server.
