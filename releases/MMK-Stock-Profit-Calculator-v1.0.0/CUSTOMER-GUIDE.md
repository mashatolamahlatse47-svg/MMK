# MMK Stock & Profit Calculator
## Customer Guide

### 1. Start the application

Open the application in your browser using the local web address provided with the installation.

### 2. Calculate a product

Enter:

- Product name
- Cost price
- Selling price
- Quantity

Select **Calculate**.

The application displays:

- Total cost
- Total sales
- Profit per item
- Total profit
- Profit status

### 3. Add stock

Under **Stock Management**, enter:

- Product name
- Cost price
- Selling price
- Quantity

Select **Add to Stock**.

The product will appear in the Stock Records table.

### 4. Sell a product

Select **Sell 1** next to the product.

The application will:

- Reduce stock by one
- Record the sale
- Record revenue
- Calculate the profit
- Add the transaction to Sales History

### 5. Restock

Select **Restock 1** when one unit is added back to stock.

### 6. Review Sales History

The Sales History section shows:

- Total sales
- Total revenue
- Total profit
- Date and time
- Product
- Quantity
- Revenue
- Profit

### 7. Backup your data

Select **Export Backup**.

Keep the downloaded JSON backup file somewhere safe.

### 8. Restore your data

Select the backup file using the file selector.

Then select **Restore Backup**.

The application will restore the saved business data and reload.

### 9. Data protection

Create regular backups.

A backup should be created before clearing browser data, changing devices, or making major changes to the application.
