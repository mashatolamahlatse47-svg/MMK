## IP TYPES

### Trade Marks
Brand names, logos, slogans and distinctive identifiers.

### Copyright
Original written content, artwork, photographs, music,
videos, software code, documents and other creative works.

### Designs
Original visual/product designs.

### Patents
Potentially patentable inventions and technical innovations.

### Software
MMK applications, website systems, source code and software products.

### Creative Assets
Photography, artwork, clothing designs, graphics, audio,
video and other original creative materials.

## OWNERSHIP

MMK IP should have documented ownership and creation records.

Keep:
- Creation date
- Creator
- Source files
- Version history
- Agreements
- Licences
- Registration numbers
- Supporting evidence
