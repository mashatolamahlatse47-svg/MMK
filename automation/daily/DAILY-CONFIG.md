## Operating Rules

- Finish before starting unrelated work.
- Test before committing.
- Commit completed work in focused commits.
- Push completed commits to GitHub.
- Do not use `git add .` blindly.
- Do not start multiple unfinished major projects at once.
- Preserve existing MMK structure.
- Reuse existing systems before creating new ones.

## Daily Workflow

1. Check repository state.
2. Identify active project.
3. Complete one main objective.
4. Test the work.
5. Save/document the result.
6. Commit completed work.
7. Push to GitHub.
8. Record the checkpoint.
9. Select the next action.
