# MMK WhatsApp Order Forms
Version: 0.2.0

A lightweight ordering form for small businesses. Customers select products,
enter their details, review their order, and send it to the business through WhatsApp.

## Open the demo
From this folder, run:
python -m http.server 8080 --bind 127.0.0.1

Then open http://127.0.0.1:8080/index.html

## Current limitations
Menu settings are stored in the current browser. They do not automatically
synchronise between devices. Configure a real business WhatsApp number before
testing orders. This local demo is not a secure multi-user hosted service.

## Before selling
- Test adding, editing and saving products.
- Test customer details and order totals.
- Test the WhatsApp message using the business owner's approved number.
- Confirm the customer's hosted link works on another phone.
- Agree on price, changes, hosting and support with the customer.
