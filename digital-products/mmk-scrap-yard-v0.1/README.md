# MMK Scrap Yard V0.3.0

A simple mobile-first scrap-yard business web interface built by MMK.

## Core Workflow

RECORD → CALCULATE → SAVE HISTORY → KNOW PROFIT

## Features

- Record purchased material
- Record purchase weight/quantity and cost
- Record sale weight/quantity and income
- Automatically calculate profit/loss
- Save transactions locally in the browser
- Dashboard with today and all-time totals
- Transaction history with newest transactions first
- Individual transaction deletion with confirmation
- Dashboard totals refresh after deletion
- Premium Personalization promotion
- MMK Founder contact options

## Run Locally

serve app -l 8092

Open http://localhost:8092

## Data

Transactions are stored locally in browser LocalStorage.

## Scope

This release intentionally stays simple. It is not a full accounting, inventory, employee, payment, or enterprise management system.
