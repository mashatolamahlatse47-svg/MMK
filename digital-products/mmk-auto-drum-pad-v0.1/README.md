# MMK Auto Drum Pad

Version: 1.0.0

A browser-based drum pad for making beats on Android and desktop.

## Live website
https://mmk-auto-drum-pad.netlify.app/

## Features
- Drum and instrument pads
- Loop controls and 16-step sequencer
- BPM and volume controls
- Pattern save/load where supported by browser storage
- WAV export

## How to use
1. Open the live website in your browser.
2. Tap a pad to play a sound.
3. Try the sequencer and playback controls.
4. Use WAV Export to export a pattern.

## Notes
This release has been published to Netlify and the owner has tested
the pads, playback controls, and WAV export.

Offline operation and recording to a file are not claimed as verified
features in this release.
