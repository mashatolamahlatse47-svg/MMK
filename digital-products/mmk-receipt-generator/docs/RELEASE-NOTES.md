# MMK Receipt Generator v1.1.0

## Release Status

Official MMK product release.

## What's New

- Automatic subtotal calculation
- Discount calculation
- Amount Due calculation
- Amount Paid input
- Automatic Change calculation
- Automatic Amount Owing calculation
- Live recalculation while entering receipt information

## Tested Example

5 Vetkoek × R10.00 = R50.00  
2 Cold Drinks × R15.00 = R30.00

Subtotal: R80.00  
Discount: R0.00  
Amount Due: R80.00

When Amount Paid is R100.00:

Change: R20.00  
Amount Owing: R0.00

When Amount Paid is R70.00:

Change: R0.00  
Amount Owing: R10.00
