## Exclusions

The following are outside the assessment scope:

- Systems not explicitly listed above
- Third-party systems
- Denial-of-service testing
- Destructive testing
- Data destruction
- Unauthorized access
- Actions outside the agreed scope

## Data Handling

MMK will collect only information reasonably required for the assessment.
Assessment evidence must be handled securely and must not be intentionally
disclosed to unauthorized persons.

## Scope Changes

Any material change to the assessment scope must be approved by the
authorized client representative before testing continues.
