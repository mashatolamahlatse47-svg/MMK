# MMK Local Services Coordinator

Version: 0.1.0

MMK coordinates customer requests with independent local service providers.

## Services
- Nanny
- Cleaning
- Maintenance
- Delivery
- Security Services
- Other Local Services

## V0.1 workflow
NEW REQUEST → REVIEWING → FINDING PROVIDER → PROVIDER CONTACTED → CUSTOMER CONFIRMED → BOOKED → IN PROGRESS → COMPLETED → CLOSED

Alternative:
CANCELLED / DECLINED / NO PROVIDER / RESCHEDULED

## Payment boundary
MMK records the customer's coordination/payment status only:
- Cash
- Pay later
- Deposit
- Finish later

MMK does not manage supplier/provider payment accounts or supplier revenue.
